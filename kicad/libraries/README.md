# Biblioteca PS28
`PS28.kicad_sym`: símbolo local TPA3255DDV, 44 pinos, fonte TI SLASEA8A p.3–4,
PowerPAD superior aterrada via dissipador (não criar pad de PCB 45).
Footprint TopEP vem da biblioteca oficial KiCad Package_SO, DDV0044D.
As propriedades/pinagem estão em revisão; não são certificação de componente ou layout.

Símbolos Device/power/Connector_Generic ficam no cache do schematic, derivados das
bibliotecas oficiais do sistema KiCad 10.0.7. Essas bibliotecas são disponibilizadas
sob CC-BY-SA 4.0 com exceção para uso de desenhos em projetos; preservar atribuição
conforme licença upstream: https://gitlab.com/kicad/libraries/kicad-symbols
Footprints embarcados: https://gitlab.com/kicad/libraries/kicad-footprints
Nenhuma licença foi atribuída automaticamente ao restante do projeto.
