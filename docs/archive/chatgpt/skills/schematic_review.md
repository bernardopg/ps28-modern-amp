# Skill — Schematic Review

Revise o schematic do PS28 Modern Amp em cinco passes:

1. **Power:** PVDD, 12 V, 3V3, grounds, polaridades, ratings.
2. **TPA3255:** modo PBTL, bootstrap, reset, fault, clip, decoupling.
3. **Analog:** input impedance, VMID, headroom, gain, LPF, AC coupling.
4. **Interfaces:** RCA, volume, source, phase, speaker, test points.
5. **Safety/testability:** fusível, TVS, DNPs, labels, probes.

Para cada problema, classifique:

- blocker;
- high;
- medium;
- low.

Não aceite ERC limpo como prova de correção elétrica.
