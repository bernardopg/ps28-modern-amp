# PCB-002 — Revisão global de layout e G2

## Objetivo

Revisar a PCB roteada inteira (corrente, retornos, laços Classe D, EMI, DFM) em
CAD e obter o gate G2. Trabalho de mesa; nenhum ensaio físico.

## Critérios de aceite

- [x] DRC/paridade sem erros não justificados
- [x] Conectividade fechada; bootstrap/desacoplamento locais revistos
- [x] Interface térmica nominal e envelopes verificados em CAD
- [ ] Larguras de PVDD/SPK/GND contra corrente calculada (IPC-2152), ramais finos justificados
- [ ] Laços de comutação, retorno de GND e separação analógica revistos contra SLASEA8A §11
- [ ] DFM JLCPCB (anel, máscara, serigrafia, panelização) sem pendência
- [ ] G2 assinado pelo proprietário

## Evidência

- `kicad/system-candidate/`: 269 footprints, 3.535 segmentos, 500 vias;
  ERC 0, DRC 0, aberturas 0, paridade 0 (2026-10-17).
- [Revisão local TPA](../../docs/tpa-local-layout-review.md);
  [fit térmico](../../mechanical/thermal-block.md).
- Pendência conhecida: PVDD tem ramais de 0,2/0,3/0,6 mm além do ramo de 1,2 mm
