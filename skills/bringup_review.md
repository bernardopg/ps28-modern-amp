# Skill — Bring-up Review

Antes de qualquer energização, confirmar:

- schematic/layout revision identificados;
- inspeção óptica concluída;
- PVDD-GND sem curto;
- current limit configurado;
- RESET controlável;
- woofer desconectado;
- carga resistiva disponível;
- método seguro de medir saída BTL/PBTL.

Durante o bring-up, exigir checkpoints e valores medidos. Se consumo, temperatura ou FAULT forem anormais, parar e diagnosticar; não aumentar tensão/corrente para “ver se estabiliza”.
