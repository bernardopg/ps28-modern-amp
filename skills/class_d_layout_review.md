# Skill — Class-D Layout Review

## Ordem de revisão

1. TPA3255 + exposed pad.
2. PVDD decoupling.
3. switching loops.
4. LC filter.
5. speaker current path.
6. ground plane continuity.
7. analog separation.
8. thermal path.
9. mechanical clearance.

## Falhas críticas

- capacitor PVDD distante;
- loop switching grande;
- analog trace sob switching node;
- GND plane partido sem justificativa;
- speaker trace estreita;
- thermal vias insuficientes;
- retorno de RCA compartilhando trecho estreito de corrente do output stage.

Compare o placement com a TPA3255EVM antes de aprovar.
